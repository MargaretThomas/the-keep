# The Keep

The Keep is a local-first tool for visualising, organising, and decluttering ChatGPT chats.

## Features

- Import ChatGPT conversation JSON
- Search and filter chats
- Group chats into categories
- Assign chats to projects
- Mark chats as keep, move, archive, or delete
- Open chats in batches for manual action
- Save organisation data locally as JSON

## Tech Stack

- Vue 3
- Vite
- JavaScript
- Plain CSS
- Local JSON files
- Browser `localStorage` for lightweight UI state
